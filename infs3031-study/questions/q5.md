## File 2: `LoginAction.java`

```java
package com.delivery;

import com.opensymphony.xwork2.ActionSupport;
import org.apache.struts2.interceptor.SessionAware;
import java.sql.*;
import java.util.Map;

public class LoginAction extends ActionSupport implements SessionAware {

    private String username;
    private String password;
    private Map<String, Object> session;

    // Struts2 injects the session map via SessionAware
    @Override
    public void setSession(Map<String, Object> session) {
        this.session = session;
    }

    public String getUsername() { return username; }
    public void setUsername(String u) { this.username = u; }
    public String getPassword() { return password; }
    public void setPassword(String p) { this.password = p; }

    @Override
    public String execute() throws Exception {

        // Connect to MySQL Deliveries database
        Connection conn = DriverManager.getConnection(
            "jdbc:mysql://localhost:3306/Deliveries", "root", "yourpassword");

        // PreparedStatement prevents SQL injection
        PreparedStatement ps = conn.prepareStatement(
            "SELECT * FROM drivers WHERE username = ? AND password = ?");
        ps.setString(1, username);
        ps.setString(2, password);

        ResultSet rs = ps.executeQuery();

        if (rs.next()) {
            // Driver found — save username to session for use across requests
            session.put("loggedInDriver", username);
            conn.close();
            return SUCCESS;  // → deliveries.jsp
        } else {
            addActionError("Invalid username or password.");
            conn.close();
            return ERROR;    // → login.jsp with error message
        }
    }
}
```

- `implements SessionAware` — gives access to the session map
- `session.put("loggedInDriver", username)` — persists the driver across requests (HTTP is stateless without this)
- `PreparedStatement` with `?` placeholders — safe from SQL injection
- Returns `SUCCESS` or `ERROR` — mapped in `struts.xml`

## File 3: `DeliveriesAction.java`

```java
package com.delivery;

import com.opensymphony.xwork2.ActionSupport;
import org.apache.struts2.interceptor.SessionAware;
import java.sql.*;
import java.util.*;

public class DeliveriesAction extends ActionSupport implements SessionAware {

    private Map<String, Object> session;
    private List<Map<String, String>> deliveries;

    @Override
    public void setSession(Map<String, Object> session) {
        this.session = session;
    }

    public List<Map<String, String>> getDeliveries() { return deliveries; }

    @Override
    public String execute() throws Exception {

        // Read the logged-in driver from the session
        String driver = (String) session.get("loggedInDriver");

        // If no session exists, redirect to login
        if (driver == null) {
            return LOGIN;  // "login" result → login.jsp
        }

        Connection conn = DriverManager.getConnection(
            "jdbc:mysql://localhost:3306/Deliveries", "root", "yourpassword");

        PreparedStatement ps = conn.prepareStatement(
            "SELECT address, recipient, status FROM deliveries WHERE driver_username = ?");
        ps.setString(1, driver);

        ResultSet rs = ps.executeQuery();

        deliveries = new ArrayList<>();
        while (rs.next()) {
            // Store each row as a map so the JSP can access it by column name
            Map<String, String> row = new HashMap<>();
            row.put("address",   rs.getString("address"));
            row.put("recipient", rs.getString("recipient"));
            row.put("status",    rs.getString("status"));
            deliveries.add(row);
        }

        conn.close();
        return SUCCESS;  // → deliveries.jsp
    }
}
```

- `session.get("loggedInDriver")` — retrieves the driver saved during login
- Returns `LOGIN` if no session — prevents unauthenticated access
- Each delivery row stored as a `Map<String, String>` so the JSP can read it with `<s:property>`

## File 4: `deliveries.jsp`

```jsp
<%@ taglib prefix="s" uri="/struts-tags" %>
<html><body>

  <h1>Deliveries for <s:property value="#session.loggedInDriver"/></h1>

  <table border="1">
    <tr><th>Address</th><th>Recipient</th><th>Status</th></tr>

    <%-- Loop over the deliveries list from DeliveriesAction --%>
    <s:iterator value="deliveries" var="d">
      <tr>
        <td><s:property value="#d.address"/></td>
        <td><s:property value="#d.recipient"/></td>
        <td><s:property value="#d.status"/></td>
      </tr>
    </s:iterator>
  </table>

</body></html>
```

- `<s:property value="#session.loggedInDriver"/>` — reads directly from the session
- `<s:iterator value="deliveries">` — loops over the list returned by `getDeliveries()`
- `#d.address` — accesses the `address` key of the current map entry

## Deployment

1. Compile both Action classes with `struts2-core.jar` and `mysql-connector-j.jar` on the classpath
2. Place `.class` files in `WEB-INF/classes/com/delivery/`
3. Place `struts.xml` in `WEB-INF/classes/`
4. Place all JARs in `WEB-INF/lib/`
5. Copy `DeliveryApp/` into Tomcat's `webapps/` folder
6. Start Tomcat — visit `http://localhost:8080/DeliveryApp/login.jsp`

---

## Request Flow Summary

```
1. Driver visits login.jsp → fills in username + password → POST /login
2. StrutsPrepareAndExecuteFilter intercepts → checks struts.xml → LoginAction
3. Interceptor stack injects username/password into LoginAction via setters
4. execute() queries MySQL drivers table with PreparedStatement
5. If valid → session.put("loggedInDriver", username) → return SUCCESS → deliveries.jsp
6. If invalid → addActionError(...) → return ERROR → login.jsp with error shown
7. On deliveries.jsp → link to /viewDeliveries
8. DeliveriesAction reads session, queries deliveries table for that driver
9. Returns list → deliveries.jsp renders it with <s:iterator>
```
