# Question 2 (25 marks) — JDBC: Insert & Retrieve from `irishpresidents` DB

---

## Database Context (from image)

```
Database : irishpresidents
Table    : presidents
Columns  : number VARCHAR(255), name VARCHAR(255), term VARCHAR(255)
```

---

## Full JDBC Solution

```java
import java.sql.*;

public class IrishPresidents {

    // --- Connection details ---
    static final String URL  = "jdbc:mysql://localhost:3306/irishpresidents";
    static final String USER = "root";
    static final String PASS = "yourpassword";

    public static void main(String[] args) {

        // try-with-resources automatically closes the connection when done
        try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {

            insertWithPreparedStatement(conn);
            retrieveWithStatement(conn);

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // -----------------------------------------------------------------------
    // PART 1 — INSERT using a PreparedStatement (precompiled statement)
    // -----------------------------------------------------------------------
    static void insertWithPreparedStatement(Connection conn) throws SQLException {

        // The ? placeholders are filled in below — values never touch the SQL string
        String sql = "INSERT INTO presidents (number, name, term) VALUES (?, ?, ?)";

        // PreparedStatement precompiles the SQL once; the DB can reuse the plan
        PreparedStatement ps = conn.prepareStatement(sql);

        // Set each ? by position (1-based index)
        ps.setString(1, "10");                  // number
        ps.setString(2, "Catherine Connolly");  // name
        ps.setString(3, "2025-2032");           // term

        // executeUpdate() runs INSERT/UPDATE/DELETE — returns rows affected
        int rowsAffected = ps.executeUpdate();
        System.out.println("Rows inserted: " + rowsAffected);

        ps.close();
    }

    // -----------------------------------------------------------------------
    // PART 2 — SELECT using a plain Statement (non-prepared)
    // -----------------------------------------------------------------------
    static void retrieveWithStatement(Connection conn) throws SQLException {

        // Statement is created without any SQL — the query is passed at execute time
        Statement stmt = conn.createStatement();

        // executeQuery() runs SELECT statements — returns a ResultSet
        ResultSet rs = stmt.executeQuery("SELECT number, name, term FROM presidents");

        System.out.println("\n--- All Irish Presidents ---");
        System.out.printf("%-8s %-25s %-12s%n", "Number", "Name", "Term");
        System.out.println("-".repeat(47));

        // ResultSet cursor starts before row 1 — next() advances it
        while (rs.next()) {
            // Retrieve each column value by the column name from the table
            String number = rs.getString("number");
            String name   = rs.getString("name");
            String term   = rs.getString("term");

            System.out.printf("%-8s %-25s %-12s%n", number, name, term);
        }

        rs.close();
        stmt.close();
    }
}
```

## Explanation of Key Concepts

### PreparedStatement (precompiled) — used for INSERT

| Feature | Detail |
|---------|--------|
| **Precompiled** | The SQL is parsed and compiled by the DB once when `prepareStatement()` is called. If called in a loop, this is faster than compiling the same SQL each time. |
| **Parameterised (`?`)** | Values are bound separately from the SQL string. This **prevents SQL injection** — user input can never break out of its placeholder and alter the query logic. |
| **`setString(index, value)`** | Binds a value to a `?` by position. Other types: `setInt()`, `setDate()`, etc. |
| **`executeUpdate()`** | Used for INSERT, UPDATE, DELETE — returns the number of rows affected. |

**Why use it here?** We're inserting user-supplied data (name, term). A PreparedStatement is the safe and correct choice.

---

### Statement (non-prepared) — used for SELECT

| Feature | Detail |
|---------|--------|
| **Not precompiled** | The SQL string is sent to the DB as-is each time `executeQuery()` is called. |
| **No placeholders** | The full SQL is written as a literal string. Fine for static queries with no user input. |
| **`executeQuery()`** | Used for SELECT statements — returns a `ResultSet`. |
| **`ResultSet`** | A cursor over the result rows. `rs.next()` advances the cursor; `rs.getString("col")` reads a value by column name. |

**Why use it here?** The SELECT has no user input — it's a fixed query — so a plain Statement is acceptable and simpler.

---

### JDBC Connection Flow (summary)

```
1. DriverManager.getConnection(url, user, pass)  → opens a Connection to the DB
2. conn.prepareStatement(sql)                    → creates a PreparedStatement
   conn.createStatement()                        → creates a plain Statement
3. ps.setString(...) / ps.executeUpdate()        → bind params and run INSERT
   stmt.executeQuery(sql)                        → run SELECT, get ResultSet
4. rs.next() + rs.getString(...)                 → iterate and read rows
5. rs.close(), stmt.close(), conn.close()        → release DB resources
```

> Note: `DriverManager.getConnection()` requires the MySQL JDBC driver JAR
> (`mysql-connector-j-x.x.x.jar`) on the classpath at compile and runtime.
